Name: Daily Dad Joke CLI
Audience: Terminal users wanting daily humor on shell startup
Goal: Native Go CLI showing a cached daily dad joke on terminal launch
Features: Fetch icanhazdadjoke, daily local cache, shell init hook
Scope: Fast <5ms startup, offline cache, PowerShell and Bash/Zsh support
Out of scope: User accounts, voting, web GUI, multiple genres
Done: Single dadjoke binary prints today's joke and hooks shell
